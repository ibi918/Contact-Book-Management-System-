# Contact-Book-Management-System-
Python Contact Book Management System using functions, dictionaries, file handling, and JSON to add, search, update, and delete contacts.

📒 Python Contact Book Management System

A beginner-friendly Contact Book application built using Python. It allows users to manage their personal contacts through a simple console-based interface.

🚀 Features

- Add new contacts
- View all saved contacts
- Search contacts by name
- Update existing contacts
- Delete contacts
- Save contacts permanently using JSON
- Simple menu-driven interface

🛠️ Technologies Used

- Python
- JSON
- File Handling
- Built-in OS Module
